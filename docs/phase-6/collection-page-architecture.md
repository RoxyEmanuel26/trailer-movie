# Collection Page Architecture

Collections (`/collection/[slug]`) are manually curated groups of movies (e.g., "The Marvel Cinematic Universe", "Best Halloween Horrors"). They act as premium editorial hubs.

## 1. Purpose
Unlike Genre pages (which are auto-populated database queries), Collections are bespoke marketing and SEO vehicles. They allow the editorial team to create highly specific pages targeting long-tail search queries.

## 2. Page Structure
- **Collection Hero:** A unique, uploaded banner image specific to the collection, overlaid with the Collection Title and an editorial description (e.g., "From Iron Man to Endgame, watch all the trailers...").
- **The List:** A grid of the movies contained in the collection. Unlike standard grids, Collection grids should support a "Custom Order" defined by the admin (e.g., chronological release order).

## 3. SEO Support
The editorial description in the hero acts as the primary SEO text for the page, allowing the injection of target keywords naturally into the page body.

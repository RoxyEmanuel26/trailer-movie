# Homepage Content Workflow

## Managing the Front Door

The homepage is the most valuable real estate on the site. Its workflow requires strict control to prevent breaking the layout or displaying broken content.

### Section Management
- The homepage is composed of horizontal "Sections" or "Rows" (e.g., Hero Carousel, "Trending Now", "Action Movies").
- **Workflow:** Senior Editors can add, remove, and reorder these sections using a drag-and-drop interface representing the homepage layout.

### Section Types & Content Assignment
- **Automated Sections:** Driven by algorithms (e.g., "Trending Now" based on views). Editor only sets the section title and limits (e.g., "Show top 10").
- **Manual Curated Sections:** Editor selects a specific "Collection" to power the row.
- **Hero Carousel:** Highly manual. Editor selects 1-5 specific movies, sets the order, and potentially overrides the default poster with a specialized wide "Hero Backdrop" image.

### Temporary Promotion Handling
- Editors should be able to schedule a section (e.g., a "Halloween Horrors" row) to appear on October 1st and automatically hide on November 1st.
- This prevents stale seasonal content from lingering if the editor forgets to manually remove it.

### Ad Slot Placement (Future Proofing)
- If ad units are used, the workflow should allow editors to drag a "Native Ad Block" between content sections to control ad density without touching code.

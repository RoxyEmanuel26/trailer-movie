# SEO Philosophy

## Purpose
The primary goal of the trailer movie project is organic discovery. Users rarely type a URL directly to watch a trailer; they search for "{Movie Name} Trailer" on Google. Therefore, SEO is not an afterthought—it is the foundational growth engine of the product.

## Core Principles
1. **Quality over Quantity:** We will not index thin, valueless pages (e.g., a genre page with only 1 movie on it). We prefer fewer, highly authoritative pages over thousands of empty ones.
2. **Consolidated Authority:** We strictly avoid diluting page rank. If there are 5 trailers for *Dune*, they all live on one single `/movie/dune` page rather than 5 separate URLs.
3. **Structured Data First:** Google cannot watch video content. We must translate the visual experience of a trailer into machine-readable JSON-LD (Schema.org) so search engines can understand it perfectly.
4. **Performance is Ranking:** Core Web Vitals (LCP, CLS, INP) are direct ranking factors. Our architecture must prioritize speed, particularly on mobile.

# Editorial SEO Governance

We must prevent accidental SEO sabotage by defining who can change what.

## 1. Automated by Default
- The vast majority of SEO metadata (Meta Titles, Descriptions, Canonical tags, Schema) is auto-generated by the backend based on the Movie data (Title, Synopsis, Release Year).
- **Why:** This ensures 100% coverage and zero blank `<title>` tags, even if editors forget to fill them out.

## 2. Manual Overrides (SEO Editor Role)
- An `SEO Editor` can manually override the auto-generated Meta Title and Meta Description for any Movie, Genre, or Collection.
- **Why:** To optimize for specific long-tail keywords that the automated template might miss (e.g., changing the auto-title "Dune: Part Two (2024)" to "Watch Dune: Part Two (2024) IMAX Trailer").

## 3. URL/Slug Immutability
- Changing a slug (`/movie/dune` -> `/movie/dune-2`) is highly restricted. It should trigger a warning in the CMS: *"Changing this URL will impact SEO. A 301 redirect will be created automatically. Proceed?"*

## 4. Rollback Behavior
- Because manual SEO edits are stored in the database, any disastrous edits can be reverted either via database backups or by simply clearing the manual override fields in the CMS, which instantly reverts the page back to the safe, auto-generated template.
